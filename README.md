# ryujou

Embedded systems engineer focused on firmware, hardware interfaces, low-power devices, and audio-enabled embedded platforms.

专注于嵌入式软硬件协同开发，主要研究 STM32 / ESP32 固件、低功耗控制、LED / LCD 设备、BLE / USB / Wi-Fi 通信、音频可视化和 FPGA 音频系统。

## Research and Engineering Focus

- Embedded firmware architecture and low-power device design
- STM32 / ESP32 peripheral control, PWM, GPIO, timers, display, storage, and sleep/wake systems
- LED effects, LCD interfaces, LVGL user interfaces, and parameter persistence
- BLE, USB CDC, Wi-Fi Web UI, UART, Modbus, and custom serial protocols
- Audio spectrum visualization and embedded audio data pipelines
- FPGA-based digital audio and OPL3 synthesis
- Reproducible firmware builds, protocol validation, and hardware-software integration

## Selected Projects

### Embedded and Hardware Systems

- [Maurya-Source](https://github.com/ryujou/Maurya-Source) - Android, iOS, ESP32-C3, BLE, Wi-Fi Web UI, and protocol implementation for a seven-channel support light.
- [Nichirin](https://github.com/ryujou/nichirin) - STM32G431 multi-mode LED/LCD system with USB streaming, audio spectrum display, and LVGL controls.
- [Peacock](https://github.com/ryujou/peacock) - STM32G030 low-power seven-channel LED controller with software PWM, gamma correction, Flash persistence, and CMake builds.
- [XTU_Badge](https://github.com/ryujou/XTU_Badge) - CR2032-powered STM32L031F6P6 badge with configurable lighting effects, sleep/wake behavior, and EEPROM settings.

### FPGA and Audio

- [zybo-opl3-fpga](https://github.com/ryujou/zybo-opl3-fpga) - Standalone OPL3 FPGA audio system for the Digilent Zybo using Vivado/Vitis 2025.2.
- [Nichirin_APP](https://github.com/ryujou/Nichirin_APP) - Android-side audio spectrum visualization and BLE data sender for experimental hardware.

### Supporting Software

- [Maurya](https://github.com/ryujou/Maurya) - Multilingual Android and ESP32-C3 firmware project for a seven-channel support light.
- [Maurya-Source](https://github.com/ryujou/Maurya-Source) - Cross-platform application, firmware, BLE, Wi-Fi Web UI, and protocol source code.
